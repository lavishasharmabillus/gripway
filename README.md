# GRIPWAY Tyres (demo website)

A single-page, motion-heavy tyre website prototype. Open `index.html` in any modern browser; it works offline.

- Rolling-tyre intro with dust, category pages, product pages with a 360° view, cart and checkout (demo only)
- All prices, dealers, reviews and the "GRIPWAY" brand are placeholder content
- Background photos on the SUV, Off-Road and Sedan pages come from Wikimedia Commons (CC BY-SA 4.0); credits are shown on each banner

To publish with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
